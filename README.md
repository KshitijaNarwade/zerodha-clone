# Zerodha Clone

A simple and functional clone of **Zerodha**, India's largest stock brokerage platform.  
This project focuses on building the **UI and basic functionality** of Zerodha's landing pages and essential features using modern web technologies.

---

## 🚀 Features

- ✔️ Clean and responsive UI similar to Zerodha  
- ✔️ Homepage layout with sections (Hero, Pricing, Products, Team, Education)  
- ✔️ Mobile-friendly design  
- ✔️ Navigation bar and footer  
- ✔️ Reusable components  
- ✔️ Organized folder structure  
- ✔️ Focus on frontend development best practices

## 📦 Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/your-username/zerodha-clone.git
```

2. Navigate to project folder:
```bash
cd zerodha-clone
```

3. Install dependencies:
```bash
npm install
```

4. Start local development server:
```bash
npm start
```
